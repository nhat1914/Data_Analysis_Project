# Machine Learning and Deep Learning Project Repository

Welcome to my **Applied AI and Data Science portfolio**, featuring end-to-end projects that combine **deep learning, predictive modeling, and automation** to solve real-world business and analytical problems.  
This repository currently includes two major projects, with more to be added in the future.

## Repository Overview

### 1. [Deep Learning for Sentiment Image Classification](https://github.com/nhat1914/Data_Analysis_Project/tree/44926f75760e69c6626f9aefb7d9f607b186335d/Machine%20Learning%20and%20Deep%20Learning%20Projects/Deep%20Learning%20for%20Sentiment%20Image%20Classification)
A computer vision project that applies **Convolutional Neural Networks (CNNs)** to classify facial emotions into categories such as *Happy, Sad, Fear, Pain, Anger,* and *Disgust*.  
It demonstrates advanced techniques in:
- Image preprocessing and data augmentation  
- Model capacity tuning and generalisation  
- Cross-domain evaluation and few-shot fine-tuning  

**Tech Stack:** PyTorch, NumPy, Pandas, scikit-learn, Matplotlib, Seaborn  

### 2. [Multi-Model Product Demand Forecasting](https://github.com/nhat1914/Data_Analysis_Project/tree/44926f75760e69c6626f9aefb7d9f607b186335d/Machine%20Learning%20and%20Deep%20Learning%20Projects/Predict%20Product%20Demand)
A forecasting automation project designed for wholesale and retail operations.  
It uses **Prophet** and **SARIMAX** models to predict weekly product demand, supporting data-driven stock and purchasing decisions.  
Includes:
- Automated data merging and cleaning  
- Comparative forecasting with accuracy metrics (MAE, MAPE)  
- Exportable results for decision support  

**Tech Stack:** Python, Pandas, Prophet, Statsmodels, scikit-learn
